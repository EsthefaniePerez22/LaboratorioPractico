# LaboratorioPractico

## Descripción

Este proyecto fue realizado para practicar **Git y GitHub**, como parte del Taller Colaborativo de GIT/GITHUB de la asignatura Organización y Arquitectura de Computadoras (Universidad Tecnológica de Panamá, II Semestre 2026).

Consiste en un sitio web donde cada integrante creó una página personal con dos tarjetas: una de presentación propia y otra sobre un tema de interés personal, manteniendo un diseño coherente entre todas las páginas.

## Tecnologías utilizadas

- Git
- GitHub
- HTML
- CSS

## Instalación

Clonar el repositorio:

```bash
git clone https://github.com/EsthefaniePerez22/LaboratorioPractico.git
```

Este proyecto fue realizado por Esthefanie Pérez (@EsthefaniePerez22), George Estrada y Richard Arauz (@Richdrakko17).

## Flujo de trabajo con Git

- La coordinadora (Esthefanie Pérez) creó el repositorio remoto en GitHub y la estructura inicial de carpetas.
- Cada integrante clonó el repositorio y trabajó en su propia rama personal:
  - Persona2_G — George Estrada
  - persona3_R — Richard Arauz
- Los cambios se integraron a main mediante merge, resolviendo conflictos de fusión cuando fue necesario.
- Se utilizó git reset --hard y push --force para corregir el historial en un caso puntual de commits desordenados.

## Tareas completadas

1. Creación del repositorio y estructura de carpetas
2. Páginas personales con tarjetas de presentación e interés personal
3. Gestión de ramas por integrante
4. Integración de cambios a main
5. Resolución de conflictos de merge
6. Documentación del proceso con Git
